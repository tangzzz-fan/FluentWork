# FluentWork UI/UX 设计文档

**版本**：V1.2　**日期**：2026年8月　**对应 PRD**：V1.4　**作者角色**：资深 UI/UX 设计师

---

## 一、设计目标与原则

### 1.1 设计目标

为"高压、时间稀缺、目标导向"的程序员用户，设计一款**打开即练、练完即走、进步可见**的口语训练 App。设计的核心矛盾是：语言训练需要放松的表达氛围，而目标用户是高度理性、反感花哨的工程师。

### 1.2 设计原则（按优先级）

1. **效率优先于愉悦**：从打开到开始说话 ≤ 2 次点击；所有核心操作支持单手完成；不做任何打断式新手引导蒙层。
2. **降低开口焦虑**：练习场景的视觉氛围要"低压力"——无分数大字报、无排名、无红色错误轰炸；错误用中性色标注，反馈永远先给肯定。
3. **状态永远可见**：AI 正在听 / 正在想 / 正在说，三种状态必须有明确的视觉和动效区分。语音产品中"系统是否还活着"的不确定感是最大的体验杀手。
4. **进步可视化**：自动化进度、实战命中、连续天数，是留存的核心动力，必须在首屏有一席之地。
5. **深色优先**：目标用户长期在 IDE 深色环境中工作，深色为默认主题，浅色为可选。

## 二、设计语言（Design System）

### 2.1 色彩

深色主题（默认）：

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景主色 | `#1A2226` | 页面底色 |
| 背景次色 | `#232E33` | 卡片、弹层 |
| 主品牌色 | `#4A7C82` | 主按钮、激活态、AI 相关元素 |
| 强调色 | `#7FB3B8` | 高亮、链接、命中徽章 |
| 正文 | `#E8EDEF` | 主文本 |
| 次要文本 | `#9AABAF` | 说明、时间戳 |
| 成功/已自动化 | `#6A9E7E` | 状态灯绿、正向反馈 |
| 训练中 | `#C9A45C` | 状态灯黄、温和提醒 |
| 待改进 | `#C97B5C` | 错误标注（中性偏暖，不用纯红） |

设计说明：整体为冷灰蓝绿（slate/teal）方向，与程序员审美契合；错误色刻意避开纯红——语言学习中的"错误"是中性事件，不是失败。浅色主题为同一色相的反转映射；**对比度验收（V1.2）**：深色下达标的对比度在浅色底上往往不达标，发版前至少对浅色主题的正文/次要文本/待改进色做一次 WCAG AA（4.5:1）验收，其余可后置。

### 2.2 字体与排版

| 层级 | 规格 | 用途 |
|---|---|---|
| 页面标题 | 20pt / 加粗 | Tab 页标题 |
| 卡片标题 | 16pt / 加粗 | 场景卡、话术块意图 |
| 正文 | 15pt / 常规，行高 1.5 | 对话气泡、文章内容 |
| 辅助文本 | 13pt / 常规 | 说明、时间戳 |
| 技术术语与代码 | 系统等宽字体（SF Mono），同正文字号 | 对话气泡与文章中出现的 cache/API/限流等中英混合术语与代码片段，提升扫读效率 |
| 英文内容 | 同字号，字重 +1 级 | 英文话术块需比中文略重，保证混排可读性 |

中文字体使用系统默认（PingFang / 思源黑体），英文使用系统无衬线；不引入自定义字体，控制包体积。

### 2.3 间距与圆角

> 单位纪律（V1.1 修订）：全文档统一使用 **pt**（iOS 逻辑单位），不再出现 px，避免设计稿与开发还原歧义。

- 间距体系：4 的倍数（4 / 8 / 12 / 16 / 24 / 32）。
- 卡片圆角 12pt，气泡圆角 16pt，主按钮圆角 24pt（胶囊形）。
- 页面安全边距：左右 16pt。

### 2.4 核心组件

| 组件 | 规格要点 |
|---|---|
| 主按钮（说话键） | 胶囊形大按钮，直径 72pt，居中于说的房间底部；三种状态：待按（静态）/ 录音中（脉冲波纹）/ 处理中（环形进度） |
| 话术块卡片 | 三段式：中文意图（顶部，加粗）/ 英文块（中部，主品牌色，可点按播放发音）/ 对比锚点（底部折叠，"你当时说：…"） |
| 状态灯 | 8pt 圆点，灰/黄/绿三态，置于话术块卡片右上角 |
| 即时反馈徽章 | 小胶囊（"地道表达 +1"），从气泡右上角弹出，1.5 秒后自动收起为气泡角标 |
| 评价卡 | 三段折叠卡：目标达成 / 问题清单 / 提高建议，默认展开第一段 |
| 骨架屏 | 语料库/历史/每日一读的加载态统一用闪烁骨架块（与卡片同形），不用转圈 spinner——工程师用户对"系统活着但没内容"的感知更准确 |

## 三、导航与整体结构

底部 3 Tab：**工作台｜闪测｜语料库**。全屏页从对应入口推入：说的房间、回顾页、每日一读、话题建议、设置。

关键路径长度审计：

- 开始练习：工作台 → 点"开始新练习" → 选场景（弹层）→ 进入说的房间 = **2 次点击**（继续上次为 1 次）。
- 闪测：底部 Tab → 直接开始 = **1 次点击**。
- 查看昨日回顾：工作台 → 历史列表点入 = **1 次点击**。

## 四、核心页面详细设计

### 4.1 工作台（首页）

**布局（自上而下）**：

1. **问候条 + 轻量数据条**：左侧"早上好，准备今天的 standup 了吗"；右侧数据呈现——本周练习用**小进度环"本周 2/3 次"**（V1.2：把 PRD 核心假设"周 3 次持续练习"变成用户可见目标，纯自我参照，不做排名与连击惩罚），话术块数与已自动化数点击进语料库。
2. **"今日三件事"轻量清单（V1.2 新增）**：练一次 / 读一篇 / 闪测一轮——给习惯一个脚手架，完成即勾销，无排名无惩罚；与进度环同属"自我参照"体系。
3. **今日入口卡**（最大卡片，主品牌色底）：文案动态生成（如"上次你练了限流方案的讨论，今天继续？"）＋ 主按钮"开始新练习"／次按钮"继续上次"。**"继续上次"体验规格（V1.2）**：进房间后 AI 首句总结上次讨论（"上次我们聊到限流方案，今天继续？"），避免用户从零回忆（技术上与 session.start 携带素材提炼一致，成本低）；创建弹层同步标注预期时长（"约 4 分钟"），管理 8-12 回合的时长预期。
4. **每日一读卡**：今日短文标题（由用户语料生成，如"一段可以直接用的 standup 汇报"）＋ 时长标签（约 1 分钟）＋ 跟读评分入口。
5. **话题建议卡**（语料 ≥ 20 个后出现）："这周可以聊：向美国同事解释降级方案"，附 3 个已练话术块缩略；未达标时显示进度激励（"再积累 6 个话术块，解锁实战话题建议"）。
6. **练习历史列表**：按时间倒序的紧凑列表项（场景图标 + 标题 + 日期 + 新增话术块数）。

**设计意图**：首页同时服务两种心智——"我现在要练"（大卡片）和"我今天进步了什么"（数据条 + 历史）。话题建议卡的进度激励把"语料积累"游戏化为可见目标，但不用分数排名。

### 4.2 说的房间（全屏沉浸页，设计权重最高）

**布局结构**：

```
┌─────────────────────────┐
│  ← 结束    场景标题      │  顶部栏（极简）
├─────────────────────────┤
│  [本局上下文/目标胶囊]   │  可收起（目标句 + 素材摘要）
│                         │
│   AI: What did you ...  │  对话气泡流
│   你: Yesterday I ...   │
│   你: The bottleneck... │  ← 右上角弹出徽章"地道表达 +1"
│                         │
├─────────────────────────┤
│  [实时转录浮层]           │  半透明，仅录音时显示
│  ━━━━━━━━━━━━          │  波形/状态条
│        ( ● )           │  说话键 72pt
└─────────────────────────┘
```

**语音状态机与动效**（本页的核心设计物）：

| 状态 | 视觉表现 | 动效 |
|---|---|---|
| 等待用户说话 | 说话键静态主品牌色 | 微弱呼吸缩放（周期 3s，幅度 3%，提示可说话） |
| 用户录音中 | 说话键外圈扩散波纹 | 波纹随音量起伏；转录浮层实时滚动文字 |
| AI 处理中 | 环形进度 | ≤ 1.5s 内完成，不显示百分比（避免焦虑），只显示"对方正在思考"的三个点动效 |
| AI 播放中 | 气泡左侧波形动画 | 用户开口即停（打断），波形立即静止 |

**即时反馈徽章（B7）**：用户话音落下、系统检测到命中已练话术块时，从该气泡右上角以 200ms 弹性动画弹出胶囊徽章（"地道表达 +1"），停留 1.5 秒后收缩为气泡右上角的一个小圆点角标。全程无弹窗、无震动、不打断 AI 接续说话。这是"强化时效性"在交互层的落地。

徽章文案纪律（V1.1 新增）：用户在练英语，正向反馈文案以英文为主 + 中文辅助（如 "Nice phrase! 地道表达 +1"），与产品语境一致；具体文案内测期 A/B。

**转录浮层与气泡的衔接（V1.1 明确）**：录音中实时转录显示在底部浮层；话音落下后转录文本以 200ms 淡入归位到对应用户气泡，浮层同步淡出——禁止浮层与气泡同时显示同一句话（双重展示的视觉噪音）。

**打断的完整视觉反馈（V1.1 细化）**：用户开口打断时，除波形立即静止外，被打断的 AI 气泡尾部加灰色截断标记（"…"弱化），明确告知"它被你打断了"而不是"它卡住了"——状态可见性原则的延伸。

**"本局上下文/目标"胶囊（V1.2 新增）**：素材上下文栏与本局目标合并为一个可收起胶囊：上部为目标句（如"目标：用上 2 个新表达汇报进度"），下部为素材摘要；AI 开场白本身示范一次目标行为；首个 AI 话轮后可收起。这是首次会话 10 秒内建立"这不是聊天，是训练系统"认知的落地——wow moment 在回顾页，但用户可能在到达之前就流失，身份认知必须前置。

**可听的状态（V1.2 新增）**：语音产品里 1-2 秒静默是最强的"是不是挂了"信号，状态不仅要可见还要可听：处理中（≤1.5 秒）加极轻的呼吸音/环境音（明显低于对话音量）；断线与降级加短促提示音；恢复时由 AI 一句话带过（"网络恢复了，我们继续"）。全部提示音克制、默认较轻且可在设置单独关闭。此项直接缓解端到端 POC 中"等太久"类 badcase。

**降低开口焦虑的细节**：

- 无倒计时、无回合分数；结束按钮常驻但不抢眼。
- **双出口设计（V1.2 重定义，替代 V1.1 单出口确认）**：顶部"结束"为统一出口，点按弹出底部条（不用模态弹窗，保留肌肉记忆），提供两个出口：主按钮**"完成并查看回顾"**（默认、正向，文案用收益框架如"看看这轮你收获了什么"）；次按钮"放弃本轮"（不保留，对应 B6，需二次确认，禁止损失框架文案如"将不会进入回顾"）。
- **自然退场（V1.2 新增）**：约 8 回合时 AI 主动递 off-ramp（"差不多聊透了，再补一个点就收尾？"），把"结束"从用户自我判断变成对话的自然节奏，同时保证回合数有上限（8-12，对应 B1）。
- 用户长时间不说话（>10 秒）：AI 主动递台阶（"Take your time. Want me to rephrase the question?"），而不是沉默等待。
- 录音中说话键旁有小字提示"说错了没关系，结束后我们一起看"。

### 4.3 回顾页（首次体验的 wow moment 承载页）

**渐进式加载（V1.1 新增，必须定义）**：评价是异步生成的（≤15 秒），用户结束会话后会立即进入回顾页，因此页面分层到达：

1. **第一层（3 秒内）**：转录按话轮展示（可回听）＋ 总结条；评价区用骨架屏占位，标注"正在分析你的表达…"；
2. **第二层（≤15 秒）**：三层评价卡、双栏对照、炼化卡依次淡入，但默认只呈现 Top 3（见下方展示纪律）；
3. 失败态：评价生成失败时保留转录，评价区显示"重试"入口（对应第五章错误态）。

**布局（自上而下）**：

1. **总结条**：本次对话时长、回合数、新增话术块数——先给正向数据。
2. **三层评价卡**（折叠卡组）：
   - 目标达成（默认展开）："你说清了 3 件事中的 2 件"，具体列出。
   - 问题清单：每条引用用户原句（可点击回听自己的录音），按 语法/地道度/信息缺失 分组；同屏最多 5 条，更多折叠。
   - 提高建议：≤3 条可复用句式，每条带"加入语料库"按钮。
3. **双栏对照区**：左"你说的"／右"更地道的版本"，差异词高亮（待改进色下划线，非红字）；每对可分别播放原音和示范音。**首次练习的回顾页中，Top 1 对照是视觉焦点**——"你的原句 → 更地道版本"是通用 AI 聊天给不了的东西，必须让用户第一眼看到（对应 PRD 风险对策：首次会话价值感知）。
4. **话术块炼化区**：3-5 张卡片横滑浏览，每张可编辑/丢弃；底部主按钮"全部入库"。
5. **底部操作**："再来一轮"（同素材）／"完成"。

**展示纪律（V1.2 新增，默认 Top 3）**：回顾页首屏默认只呈现 3 个最高价值点——**1 条最响亮的双栏对照、1 个最值得改的问题、1 条可复用建议**，其余收进"查看全部"。同时默认展开 10+ 条信息会淹没"先肯定后改进"的阅读顺序，少而精的对照比 8 条对照更有冲击力，与评价体系"宁可少而准"的纪律（Prompt 文档 3.2 数量约束）一脉相承。

**注册时机的交互（V1.2 新增，对应 PRD G4）**：未注册（游客态）用户在回顾页点"全部入库" → 页内底部轻量面板（不离开回顾页）："保存到语料库需要先登录"，支持手机号/邮箱验证码；登录成功后原位继续入库并给"语料库 +N"反馈；拒绝登录则允许游客态暂存本机（后续注册自动归并，后端 merge 幂等，见后端方案 3.2）。面板文案用收益框架："登录后，这些表达才真正属于你"。

（发音评测卡随 V1.1 上线，插入双栏对照区与炼化区之间：整体评分环形图占 1/4 屏宽刻意弱化视觉权重 + ≤3 个发音问题词条。）

**设计意图**：信息量大但必须保持"先肯定后改进"的阅读顺序。

### 4.4 闪测页

**交互模型**：全屏卡片流，一卡一题。

```
┌─────────────────────────┐
│  闪测        第 3/10 题   │
│                         │
│   需要推迟某个话题时说：   │  中文场景意图（大字居中）
│                         │
│        ( ● )           │  按住说话
│                         │
│   ⏱ 5                  │  倒计时（细环，不闪烁）
└─────────────────────────┘
```

作答后的判定等待设计（V1.1 新增）：判定链路为 ASR + LLM 异步处理（1-3 秒），"作答后立即翻卡"不成立。实际交互：话音落下 → 卡片以 300ms 翻转动画进入"判定中"背面（细环动效 + "正在听你说的…"，不用百分比）→ 判定返回后展示对照：你说的（转录）／ 标准话术块，判定结果用状态灯色（成功绿 / 失败黄，不用红）＋ 一句话理由。超过 3 秒未返回（后端超时兜底）：先展示对照与转录，判定结果标记"待确认"并可稍后刷新，不阻断后续题目。失败卡自动插入本轮尾部（调度规则的用户可感知呈现："这张卡稍后还会再来一次"）。

**倒计时语义与跳过出口（V1.2 修订）**：5 秒作答倒计时不是从卡片出现就开始，而是"**准备期 1 秒**（读题，倒计时不动）+ 作答 5 秒"；`response_ms` 计时起点为准备期结束、开始录音之时（与后端 DrillRecord 口径对齐，见 Prompt 文档数据模型）。卡片下方加不抢眼的"这题卡住了"文字按钮：跳过 = 调度记失败并插入本轮尾部，但由用户主动选择，比盯着倒计时走完更能降低焦虑。

**结算页**：本轮成功率环图 + "已自动化"话术块 +N 的高亮动画 + 连续天数。不做排行榜。

**时长纪律**：单轮 10 题硬性控制在 5 分钟内——这是碎片时间产品，结算页文案强化"明天再来"。

### 4.5 语料库页

- 顶部：搜索框 + 两个筛选 Chip 组（场景：Standup/Review/1:1…；功能：表达反对/请求澄清/汇报进度…）。
- 列表：话术块卡片三段式（见 2.4），右上角状态灯，右滑快捷操作（收藏/删除）。
- **进步证据（V1.2 新增）**：已自动化的块在卡片上显示"开会用上过 N 次"（real_use_count 字段，"练了真能用上"的最强证据）；对比锚点区提供"回听自己原话"入口，把自输出镜像原则延伸到语料库；锚点首次展示默认展开，之后折叠。
- 空态（首次进入）：插画 + "完成第一次对话练习，这里就会长出你的第一批表达" + 按钮"去练习"。

### 4.6 每日一读页

- 文章卡片：标题 + 预计时长 + 正文（英文为主，长难句可点按看中文注释）。
- 底部播放条：AI 朗读（可调速 0.8x/1.0x/1.2x）；跟读模式切换——逐句出现，跟读后可回听自己的录音与示范音对比（MVP 不出分）。**无分期替代反馈（V1.2 新增）**：句级自评"听得出/含糊"（点句二选一，记录不计分）＋ 录音与示范的波形对照播放，回答"不出分时跟读的意义是什么"；逐句即时评分随发音评测 V1.1 上线。
- 历史归档按日期分组（V1.1 商业化后：免费用户仅见近 7 天）。

### 4.7 话题建议页

话题卡纵向流：每张卡含 话题标题（如"向下周 standup 同步缓存方案进展"）＋ 场景说明一句话 ＋ 可调用话术块清单（3-5 条，已自动化的排前面并带绿色状态灯）＋ 开场句（可一键播放跟读）。卡片底部："已和真人聊过"打卡按钮，打卡后可选自评顺畅度（三档表情量表）。

### 4.8 订阅页（V1.1 随商业化上线，MVP 期入口隐藏）

MVP 期全免费，设置页不展示订阅入口；服务端远程开关控制，V1.1 验证节点到达后一键放出，无需发版。

- 顶部：价值主张一句话（"让每一次练习都有积累"）。
- 中部：免费 / Pro 权益对比表（两列，Pro 列高亮边框）。
- 底部：年付（主推，标"省 40%"）／月付 双按钮 + 7 天试用说明 + 恢复购买入口。
- 文案纪律：不写"限时优惠"等施压话术；转化触点页（额度用尽、语料库满）采用"展示你已有的积累 + 升级保留"的正向框架。

## 五、空态、错误态与边界场景

| 场景 | 设计 |
|---|---|
| 首次进入（未登录） | **演示素材直接作为主路径**（A5）：首次用户无需任何输入即可完整走完"说 → 回顾 → 入库"闭环；注册后置到第一次"保存语料"时触发；创建弹层默认停留在一句话描述 Tab |
| 麦克风权限拒绝 | 非阻断式说明条："听不到你就没法练啦"，附跳转设置按钮；闪测和对话共用一次授权 |
| 网络中断（对话中） | 状态条提示 + 自动降级为文本对话模式；恢复后询问是否切回语音 |
| AI 生成失败（回顾页） | 保留原始转录可回听，评价区显示"评价生成失败，点此重试"，不留空白页 |
| 语料库为空时进闪测 | 空态引导去完成一次"说"，不允许空跑 |
| 弱网浏览（语料库/历史/每日一读） | 右上角轻量"离线模式"标识，内容走本地缓存（工程支持已就绪，见 iOS 文档 §五），不留空白页 |
| 素材超长/为空 | 实时字数提示；超限截断并说明"将基于前 2000 字生成" |

## 六、动效规范

- 全 App 动效时长档位：微交互 150-200ms（徽章弹出、按钮反馈）、页面转场 250-300ms（右推/上滑）、状态动效用循环动画（呼吸、波纹）。
- 缓动统一使用 ease-out；禁止弹性过强的 spring（工程师用户群，花哨动效会减分）。
- 语音相关动效必须与真实音频状态绑定（波纹随音量、播放波形随进度），不做"假动画"——状态可见性原则（1.2 第 3 条）。
- 状态提示音（见 4.2"可听的状态"）与动效同纪律：克制、明确、可关闭；音效与视觉状态一一对应，不重复播报。

## 七、无障碍与适老化（V1.1 强化）

- 所有交互元素触控热区 ≥ 44×44pt。
- 状态灯不单独依赖颜色：灰/黄/绿同时配图标（○/◐/●）；深色背景下灰点圆点对比度需过 WCAG AA（4.5:1）验收，不达标则用空心/实心形态差异补强。
- 支持系统动态字体，正文最大放至 130% 时布局不破裂。
- 英文内容均支持点按发音，兼顾"看得懂但读不出"的用户。
- VoiceOver 规范（V1.1 新增）：波形动画、状态灯、徽章等纯视觉元素必须配 accessibilityLabel（如徽章："命中已练表达，地道表达加一"）；徽章 1.5 秒自动收起对 VoiceOver 用户不可感知，命中时额外发送一次无障碍公告（UIAccessibility.notification）。
- 触觉纪律：全 App 不使用震动反馈（与 B7 "无震动"一致，避免打断沉浸感）。

## 九、待验证的设计假设（建议内测埋点验证）

1. 说话键的"呼吸提示"是否足以引导首次用户开口（备选：首次进入显示手势引导动画；兼备选：AI 先开口示范以降低空白开场压力）。
2. 即时反馈徽章 1.5 秒的停留时长是否合适（过短无感知，过长干扰）。
3. 话题建议卡的打卡率，以及打卡按钮的措辞（"已和真人聊过" vs "今天就用它"）。
4. 首次回顾页双栏对照的呈现策略是否提升次日回访（wow moment 假设验证）。
5. 发音评分弱化展示的弃用率影响（随发音评测 V1.1 上线时再做对比实验：强展示 vs 弱展示）。
6. 注册提示时机的流失（V1.2 并入）："全部入库"点按 → 登录完成转化率；拒绝登录后游客态暂存的后续注册回流率。
7. 回顾页默认 Top 3 展示 vs 全量展示对次日回访的影响（V1.2 并入）。

## 一、跨文档一致性评审（12 条）

| # | 问题 | 处理结果 | 落盘位置 |
|---|---|---|---|
| 1 | 北极星（周 ≥1 次）与核心假设（周 3 次+）错位 | 新增并列核心信号"周练习 ≥3 次占比"，内测复盘两数并看 | PRD §三/§十一；启动书 §一、M5 |
| 2 | B7 注入时序假设（800ms 可能只影响下下轮） | POC 新增 V8 有效注入窗口测量 + T9 用例；技术方案预设三档退路（当轮确认/下轮开局确认/仅徽章） | 技术方案 3.3；注入验证文档 |
| 3 | 文档版本与口径不一致 | 全库升版对齐（见下方版本快照）；内测人数统一 20 人；RACI 更新为人类 + Agent 模式 | 启动书 §4.1 及各文档头部 |
| 4 | 数据模型与契约缺口 | `is_favorite`/`pinned_at` 字段 + 收藏接口；`DELETE /materials/:id`；`deletion_receipts` 表；锚点加密边界定案（衍生数据不加密 + 级联脱敏 + 隐私政策告知） | 后端 §3.1/§3.2/§四 |
| 5 | 文本降级无契约 | 新增 `POST /sessions/:id/messages`；iOS 状态机补文本模式事件 | 后端 §四；iOS 文档 §2.2 |
| 6 | 匿名→注册归并无设计 | PRD G4（P0）；游客身份 + `POST /auth/guest` + `POST /account/merge`（幂等），W3 随 session 模块交付 | PRD §7.7；后端 §3.2 要点 5/§四 |
| 7 | 人类承载力风险 | **决策：不处理**——Agent 接入已覆盖产能问题（负责人拍板） | 团队分工文档（既有门禁机制） |
| 8 | W8 提审与内测同周过紧 | 提审提前到 W7 末（feature-complete），W8 专做审核修复 + 内测；招募提前到 W0 | PRD §十；技术方案 §八；启动书 M3/M4 |
| 9 | "免费额度覆盖内测"是未验证假设 | W0 算账（人均日分钟 × 20 人 × 4 周），写入供应商确认记录；不够在压测窗口谈加量 | 技术方案 2.1；启动书 M0 |
| 10 | 素材提炼与"2 次点击开口"摩擦 | 定稿：A1 有预期 loading（进度文案 + 预期时长）；A2 ≤1s 不阻塞。未选"先进房间后台提炼"（依赖未验证的注入能力） | PRD §7.1 |
| 11 | B2 "≥60% 素材引用"缺测量方法 | 自动近似口径：A1 提炼产出关键词 Top 10 → 网关统计话轮命中率 → 每周人工抽检校准 | Prompt 文档 3.1 |
| 12 | 静默推送需轮询兜底 | 静默推送只做加速，客户端进页面主动拉取兜底（双向写明） | 后端 5.2；iOS 文档 §六 |

**快速清单**：72px→72pt 全库清理；内测人数统一 20；`deletion_receipts` 补表；流水线命名口径统一（"读"="回顾"，指标记为"说 → 回顾 → 入库"）。
